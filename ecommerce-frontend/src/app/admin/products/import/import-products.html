Bulk Product Import

Upload a CSV or XLSX file to add many products at once.

File format

Put these headers in the first row. Rows with errors are skipped and reported; the other rows are still imported.

Name
Required, up to 100 characters
Price
Required, greater than 0
CategoryName or CategoryId
One is required. A new category name is created automatically.
Description
Optional, up to 1000 characters
ImageUrl
Optional, up to 500 characters
StockQuantity
Optional whole number. Blank or missing columns give each product a stock of 10.
ReorderLevel
Optional whole number. Blank or missing columns use 2. A product is low stock at or below this number.
